# YousotuNeet's Home Page — BBS + Terminal v4

2000年代初頭の個人ホームページをイメージした静的HTMLの個人サイトです。ターミナルで `neet` パッケージを「インストール」すると、スレッド一覧・レス表示・ページ構成が2ch風に切り替わります。

> **補足**：2ch風表示はオリジナルのパロディUIです。実在の掲示板とは無関係です。`sudo` / `apt` はブラウザ内で再現した疑似コマンドで、実際の権限昇格・ソフトウェアインストールは行いません。

## 起動

1. ZIPを展開する。
2. `index.html` をブラウザで開く（分割版）。
3. 単一ファイルで使いたい場合は `standalone.html` を開く（CSS/JS同梱）。

外部依存はありません。GitHub Pages / Cloudflare Pages / 普通のHTTPサーバーに静的ファイルとしてそのまま配置できます。

## 新機能：ターミナル

| コマンド | 動作 |
|---|---|
| `sudo su` | 疑似rootモードを開始。プロンプトが `root@YousotuNeet:/#` に変化 |
| `sudo cat /root/secret.txt` | 非公開風の隠しテキストを表示 |
| `cat /root/secret.txt` | guestは拒否。rootモードなら閲覧可 |
| `sudo apt install neet` | サイト全体を2000年代2ch風UIに変更。設定をローカル保存 |
| `sudo apt remove neet` | 従来のBBS＋ターミナルUIに復帰 |
| `apt install neet` | rootモード中のみ実行可能 |
| `exit` | rootモード中ならguestに戻る。guestなら端末を閉じる |
| `status` | 現在のユーザー種別とneet導入状態を表示 |
| `help` | 利用可能コマンドの一覧 |
| `theme amber` / `theme green` / `theme classic` | ターミナルの配色を変更 |

`sudo` のサブコマンドはTabキーで候補補完できます。端末の履歴は↑↓。端末以外にフォーカス中は `/` または `Alt + T` で入力欄に移れます。

**初期状態では従来のBBS表示です。** 初めから2ch風にしたい場合はサイト表示後に `sudo apt install neet` を実行してください。設定はブラウザの `localStorage` に保存されます。保存が無効な環境ではそのセッション中のみ有効です。

## 2ch風モードの変化

- 赤色の「YousotuNeetちゃんねる」見出し
- 左側の板メニュー、青いリンク、灰色背景
- スレッド一覧は数字付きのテキストリンク（レス数を括弧表示）
- スレッド詳細は枠付きカードをやめ、名前・日時・レス本文を並べた素朴な表示
- ターミナルは画面下の横幅いっぱいに移動（モバイルも表示可能）
- 自己紹介や制作物、リンク先、落書き帳は元のデータを維持

## 編集するファイル

- `index.html`: ページの外枠
- `styles.css`: 通常モードと2ch風モードの両方のスタイル。下部の `.neet-installed` が今回の追加分
- `data.js`: **自己紹介・制作物・リンク・日記を編集するメインファイル**
- `app.js`: ページ・ターミナル・neet疑似パッケージの動作
- `standalone.html`: 上記3つをHTMLに内包した単体版。編集後は単体版の再生成が必要
- `assets/favicon.svg`: サイトアイコン
- `DESIGN.md`: UI仕様
- `preview-*.png`: デザインのサンプル

## 制限・安全性

- このサイトのターミナルはJavaScriptによる**安全なコマンドシミュレーター**で、端末・PCのファイルへのアクセスやサーバーでのシェル実行は行いません。
- `/root/secret.txt` は `app.js` 内に記述された演出用テキストです。秘密情報や実際の認証情報の保存には使わないでください。ブラウザソースを見ると内容は分かります。
- `sudo su` のrootはUI内の状態フラグで、OS権限やサーバー権限を取得するものではありません。
- 落書き帳はそのブラウザ内だけのローカル機能です。他の訪問者と投稿を共有する公開掲示板にはなっていません。
- 訪問カウンターもブラウザ単位です。
- 外部リンクのうち未設定のURLは「準備中」と表示されます。公開前に `data.js` を編集してください。
